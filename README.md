# premotio.com — آینه‌ی استاتیک (Scrape)

این پوشه خروجی build شده‌ی سایت `https://premotio.com/` است که در تاریخ 2026-11-09 دانلود شده.

## محتویات

- `index.html` — صفحه اصلی
- `legal/*/index.html` — صفحات Terms, Privacy, Cookies, Refunds, License, Acceptable Use
- `_nuxt/*.js` — چانک‌های جاوااسکریپت (Nuxt 3 / Vue 3)
- `_nuxt/*.css` — استایل‌ها
- `_nuxt/*.svg`, `pictures/*.webp`, `customization/*.webp`, `library/*.webp` — تصاویر
- `fonts/InterTight-Variable.woff2` — فونت
- `_payload.json`, `_scrape-report.json` — داده‌های Nuxt و گزارش دانلود

## اجرای لوکال

چون سایت از مسیرهای مطلق (`/_nuxt/...`) استفاده می‌کند، باید از ریشه‌ی همین پوشه سرو شود:

```powershell
cd premotio-scrape
python -m http.server 8123
```

سپس باز کنید: `http://localhost:8123/`

## نکته‌ها

- این خروجیِ کامپایل‌شده‌ی Nuxt است؛ سورس اصلی Vue (فایل‌های `.vue`، تنظیمات build و کد سرور) به‌صورت عمومی سرو نمی‌شود و در نتیجه قابل استخراج نیست.
- اسکریپت دانلود: `../scrape.mjs` — اسکریپت بررسی ارجاع‌ها: `../verify.mjs`
- محتوای سایت متعلق به premotio است و این آینه صرفاً برای مطالعه/استفاده‌ی شخصی دانلود شده است.


## نسخهٔ بهین راهبرد پارسی — ۱۴۰۵/۰۸/۱۸

محتوای صفحهٔ اصلی بر اساس تصاویر مرجع به بهین‌تک، اودین، سندبان، زریان و نمایشگاه اتوکام اختصاص یافته است. رنگ‌ها، ساختار، کارت‌ها، انیمیشن‌های WebGL، اسکرول و نقاط شکست قالب اصلی حفظ شده‌اند. پشتیبانی فارسی با فونت محلی Vazirmatn و حرکت کلمه‌ها به‌جای جدا کردن حروف اضافه شده است.

- `behin/content.css`: سازگاری متن فارسی با همان قالب.
- `behin/content.js`: تکمیل لینک‌ها و شناسه‌های بخش‌ها در نسخهٔ استاتیک.
- `behin/content-v3.json`: مرجع متن‌های استفاده‌شده؛ این فایل به‌صورت خودکار محتوای بسته‌های کامپایل‌شده را بازسازی نمی‌کند.
- `pictures/` و `library/wall.webp`: تصاویر سازمانی ساخته‌شده برای همان کارت‌های متحرک.
- `customization/` و `devices/`: تصاویر نمایشی و فایل‌های لازم برای کامل شدن صحنه‌های اصلی. تصاویر پنل‌ها تصویرسازی مفهومی هستند.
- دکمهٔ درخواست جلسه، برنامهٔ ایمیل را با نشانی `info@behinrpco.com` باز می‌کند؛ ثبت جلسه در سرور یا ارسال خودکار ایمیل پیاده‌سازی نشده است.

اجرای محلی همچنان بدون build و از ریشهٔ همین پوشه است. این پروژه خروجی کامپایل‌شده است و تغییر متن باید در HTML و بستهٔ جاوااسکریپت مربوط نیز هماهنگ شود.


## انتشار در GitHub Pages

فایل `.nojekyll` باید همراه `index.html` در ریشهٔ انتشار باقی بماند تا پوشهٔ `_nuxt` حذف نشود. فایل‌ها و پوشه‌های پروژه را با همین ساختار منتشر کنید.

مسیر پایه پیش از راه‌اندازی Nuxt از URL صفحه تعیین می‌شود. مسیر منابع به صورت نسبی است؛ در نتیجه سایت هم در ریشهٔ لوکال و هم زیر مسیر یک مخزن مانند `/Behin_elecomp/` کار می‌کند. برای انتشار از شاخه، در Settings → Pages شاخهٔ موردنظر و پوشهٔ `/ (root)` را انتخاب کنید.


## بازنگری محتوا و تصاویر

- معرفی محصولات بر اساس اطلاعات تأییدشده: اودین (پلتفرم سازمانی بر پایهٔ Odoo)، سندبان (OCR هوشمند)، زروان (دستیار و ایجنت سازمانی).
- فونت فارسی: Vazirmatn با وزن‌های ۳۰۰ تا ۶۰۰؛ مجوز همراه فایل‌ها در `fonts/Vazirmatn-OFL.txt` است.
- هفت تصویر سه‌بعدی بدون نوشته با ابزار image_gen تولید شده‌اند؛ نسخه‌های بهینه در `behin/images/` و شرح ساخت آن‌ها در `behin/images/generation.json` قرار دارند.
- تب‌های «معرفی» و «کاربردها» اطلاعات مرتبط با هر محصول را نمایش می‌دهند. نام‌های ERP، OCR و Agent جای عددهای تزئینیِ کارت محصولات را گرفته‌اند.
- تصاویر، تصویرسازی مفهومی‌اند؛ تصویرِ رابط واقعی محصول محسوب نمی‌شوند. مکالمهٔ بخش هوش مصنوعی نیز یک مسیر نمونه برای معرفی کارکردهاست.


## فونت و نشان بارگذاری

فونت فعال صفحه و واژه‌نشان فارسی Vazirmatn است. لودر از نشان بهین در `behin/loading-mark.svg` استفاده می‌کند؛ شمارنده و حرکت خروج قبلی حفظ شده‌اند.


## تایپوگرافی فارسی و تراز متن‌ها — ۱۴۰۵/۰۸/۱۹

وزیرمتن با نقش‌های ثابت متن (۱۶–۱۷ پیکسل)، عنوان کارت (۲۲–۲۴)، تیتر بخش (۳۰–۵۶) و تیتر اصلی (۳۲–۷۲) تنظیم شده است. قواعد خوانایی، تراز، فاصله و پاسخ‌گویی از ui-ux-pro-max و ui-styling با ساختار فعلی Nuxt تطبیق داده شده‌اند؛ وابستگی جدیدی اضافه نشده است.

حرکت واژه در تیترهای فارسی به نمایش کامل عبارت تبدیل شده تا حروف و کلمات از وسط بریده نشوند. توضیحات پلکانی هم‌تراز شده‌اند، ترتیب کارت‌ها راست‌به‌چپ است و بالای تیتر محصولات برای نوار ثابت سایت فاصله دارد. رنگ‌ها، تصاویر، صحنه‌ها و حرکت کارت‌ها حفظ شده‌اند.
