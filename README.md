# premotio.com — آینه‌ی استاتیک (Scrape)

این پوشه خروجی build شده‌ی سایت `https://premotio.com/` است که در تاریخ 2026-11-09 دانلود شده.

## محتویات

- `index.html` — صفحه اصلی
- `legal/*/index.html` — صفحات Terms, Privacy, Cookies, Refunds, License, Acceptable Use
- `_nuxt/*.js` — چانک‌های جاوااسکریپت (Nuxt 3 / Vue 3)
- `_nuxt/*.css` — استایل‌ها
- `_nuxt/*.svg`, `pictures/*.webp`, `customization/*.webp`, `library/*.webp` — تصاویر
- `fonts/InterTight-Variable.woff2` — فونت
- `_payload.json`, `_scrape-report.json` — داده‌های Nuxt و گزارش دانلود

## اجرای لوکال

چون سایت از مسیرهای مطلق (`/_nuxt/...`) استفاده می‌کند، باید از ریشه‌ی همین پوشه سرو شود:

```powershell
cd premotio-scrape
python -m http.server 8123
```

سپس باز کنید: `http://localhost:8123/`

## نکته‌ها

- این خروجیِ کامپایل‌شده‌ی Nuxt است؛ سورس اصلی Vue (فایل‌های `.vue`، تنظیمات build و کد سرور) به‌صورت عمومی سرو نمی‌شود و در نتیجه قابل استخراج نیست.
- اسکریپت دانلود: `../scrape.mjs` — اسکریپت بررسی ارجاع‌ها: `../verify.mjs`
- محتوای سایت متعلق به premotio است و این آینه صرفاً برای مطالعه/استفاده‌ی شخصی دانلود شده است.


## نسخهٔ بهین راهبرد پارسی — ۱۴۰۵/۰۸/۱۸

محتوای صفحهٔ اصلی بر اساس تصاویر مرجع به بهین‌تک، اودین، سندبان، زریان و نمایشگاه اتوکام اختصاص یافته است. رنگ‌ها، ساختار، کارت‌ها، انیمیشن‌های WebGL، اسکرول و نقاط شکست قالب اصلی حفظ شده‌اند. پشتیبانی فارسی با فونت محلی Vazirmatn و حرکت کلمه‌ها به‌جای جدا کردن حروف اضافه شده است.

- `behin/content.css`: سازگاری متن فارسی با همان قالب.
- `behin/content.js`: تکمیل لینک‌ها و شناسه‌های بخش‌ها در نسخهٔ استاتیک.
- `behin/content.json`: مرجع متن‌های استفاده‌شده؛ این فایل به‌صورت خودکار محتوای بسته‌های کامپایل‌شده را بازسازی نمی‌کند.
- `pictures/` و `library/wall.webp`: تصاویر سازمانی ساخته‌شده برای همان کارت‌های متحرک.
- `customization/` و `devices/`: تصاویر نمایشی و فایل‌های لازم برای کامل شدن صحنه‌های اصلی. تصاویر پنل‌ها تصویرسازی مفهومی هستند.
- دکمهٔ درخواست جلسه، برنامهٔ ایمیل را با نشانی `info@behinrpco.com` باز می‌کند؛ ثبت جلسه در سرور یا ارسال خودکار ایمیل پیاده‌سازی نشده است.

اجرای محلی همچنان بدون build و از ریشهٔ همین پوشه است. این پروژه خروجی کامپایل‌شده است و تغییر متن باید در HTML و بستهٔ جاوااسکریپت مربوط نیز هماهنگ شود.
